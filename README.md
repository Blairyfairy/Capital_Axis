# CapitalAxis
![CapitalAxis emblem](assets/mark.svg)

Executive Investment & Decision Intelligence Studio — Blair Page.

A standalone interactive demonstration of capital budgeting for a fictional cold-chain modernization initiative. Includes discounted cash flow, downside/base/upside comparisons, operational control gates and JSON export. All assumptions are illustrative. No original academic submission is included.

## Deploy
Upload these files to a GitHub repository and enable GitHub Pages from the main branch root. No dependencies or API keys required.
